SONRI

Platform riset kesehatan gigi. Analisis gambar berjalan di perangkat, dengan konektivitas untuk akun dan sinkronisasi yang diizinkan.

Rilis riset, bukan layanan diagnosis. Makna kelas model dan akurasi klinis belum diverifikasi. Jangan memasukkan data pasien nyata. Hosting dan distribusi tester belum diaktifkan.

Memulai riset

  1. Pasang APK riset dari undangan resmi operator atau artefak GitHub yang diperiksa.
  2. Gunakan kunci layar perangkat; baca persetujuan dan simpan kode pemulihan secara pribadi.
  3. Gunakan fixture sintetis. Sinkronisasi cloud hanya tersedia setelah operator menyediakan project Spark terpisah.

Tidak ada sinkronisasi gambar atau pelatihan otomatis. Tidak ada biaya server inferensi per foto.

Dashboard kuota operator

Angka di bawah adalah input manual dari Console provider, bukan telemetry langsung. Tidak ada kredensial atau catatan medis pada halaman ini. Ambang 80% adalah peringatan operasional, bukan jaminan pembatasan tagihan. Jangan menghubungkan billing atau meningkatkan paket.

Skenario pertumbuhan

Asumsi: 20% aktif harian, dua sesi per hari, 20 head per sesi, satu edit per hari, tiga catatan tersimpan/akun, head + tiga revisi, 16 KiB/dokumen. Estimasi ini mengabaikan variasi indeks dan retry sehingga bukan kuota yang dijamin.

Privasi dan hak pengguna

Identitas akun dan preferensi disimpan pada project riset pemilik. Catatan sintetis dienkripsi dengan kunci acak pemulihan milik pengguna; foto tetap di perangkat. Data pasien dan penelitian nyata belum boleh disinkronkan. Login atau nama peninjau tidak memverifikasi profesi.

Ekspor JSON/PDF melalui aplikasi menghasilkan salinan tidak terenkripsi yang Anda kelola sendiri. Penghapusan lokal tidak menghapus salinan ekspor atau semua revisi cloud. Permintaan penghapusan akun memerlukan operator untuk menghapus revisi, grant, profil dan akun Auth, lalu memverifikasi hasilnya.

Kehilangan kode pemulihan dan seluruh perangkat dapat menghilangkan akses permanen. Penarikan partisipasi tidak melatih, menghapus atau mengirim data secara otomatis; operator harus memproses permintaan yang relevan.

Pembaruan dan dukungan

Belum ada metadata rilis publik yang ditandatangani oleh pemilik. Bobot RF-DETR tidak dibagikan. Mekanisme pembaruan diuji dengan kernel ONNX sintetis; itu bukan model klinis. APK sideload tidak menerima pembaruan Play Store diam-diam.
