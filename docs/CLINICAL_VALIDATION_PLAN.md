# Clinical validation plan — not completed

A qualified clinical lead and independent coding reviewer must sign off symptoms, emergency pathways, rules, terminology edition, exam gates, pediatric guardian flow and intended use before release. Record approver identity/reference/date in a controlled review system; no approval is inferred from this document.

Create a representative deidentified, authorized, independently annotated cohort with actual examination reference standards. Use frozen patient/duplicate-separated train/validation/test partitions. Prespecify per-class sensitivity, specificity, precision, recall, F1, AUROC where applicable, localization IoU/mAP, calibration/error bars and clinically acceptable thresholds. Report denominators, confidence intervals, class imbalance and failure modes.

Assess emergency false negatives, abstention, poor quality, nonoral inputs, cropped/mirrored images, dentition, age, device, site and skin/mucosal variation. Evaluate subgroup performance and external distribution shifts. Use silent prospective review before any patient-facing clinical inference. Human disagreement/adjudication must be documented.

No numeric performance target or result is claimed here. Freeze thresholds with clinical approval; install a model only after licensing, security, provenance and prospective validation review. Retain rollback and adverse-event reporting procedures.
