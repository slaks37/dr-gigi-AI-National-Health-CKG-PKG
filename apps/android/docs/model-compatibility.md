RF input is `input` float32 `[1,3,704,704]`; outputs are `dets` float32 `[1,300,4]` and `labels` float32 `[1,300,5]`. IR 8 / ONNX opset 17; no external tensor files. Initializer storage is 121,139,976 bytes. Full graph operators/counts are recorded from actual ONNX inspection in `../evidence/model-graph-audit.v1.json`, including GridSample, LayerNormalization, MatMul and Softmax. These require the full ORT Android CPU build; a reduced/mobile graph is not assumed compatible.

Decode sRGB and EXIF → half-pixel bilinear resize to 704 square (no antialias/letterbox) → RGB / 255 → ImageNet mean `[.485,.456,.406]`, std `[.229,.224,.225]` → NCHW. Decode actual normalized cxcywh/logits → sigmoid → stable top 300 query/class pairs → strictly >0.25 → clip valid boxes → max 200. Slot zero and multiple classes per query are retained. This is a port of the existing reference adapter, **not proof of the original training transform or background/class semantics**. Complete raw tensor comparisons and geometric tests are required; counts alone are insufficient.

The exact FP32 baseline is unchanged: no FP16/INT8, ORT-format conversion, reduced resolution, XNNPACK or NNAPI enablement. ORT graph optimization is ALL_OPT at session load, on both reference and Android. Unmeasured acceleration is not represented as a performance improvement. Quantization requires an authorized calibration/evaluation dataset plus class-contract resolution and per-class false-negative comparison; none is available yet. No new training or paid resources were started.

Weight size is not peak memory. ORT execution arenas, image buffers, intermediate activations and app heap increase usage; only the actual device measurements in the benchmark apply. Android 10+ ARM64 is a build target, not a universal supported-phone claim. Physical 4/6/8 GB phones and the 15-second target remain untested.

The generic RF-DETR [source license](https://github.com/roboflow/rf-detr/blob/main/LICENSE) does not establish rights to a third party's dental checkpoint, training images or Android redistribution. Existing owner-local notice is evidence of the prior local research authorization, not a public model distribution grant. The user delegated the packaging choice without supplying further proof; therefore weights remain outside Git, APK and public CI. Securely obtain checkpoint-specific permission before copying to additional phones or distributing a model bundle. An acknowledgment field is not legal approval.

The original Phase 3 [label provenance report](../../../docs/validation/phase3-label-provenance.md), [additional-model readiness](../../../docs/validation/phase3-additional-models.md) and [security incident status](../../../docs/validation/phase3-security-status.md) remain applicable. This Android change does not revoke the previously exposed credential or close that incident; owner nonsecret revocation evidence is still required. The offline APK does not use or copy that credential. It does not install the four additional model candidates or treat missing/incompatible checkpoints as operational.

Before any clinical use: obtain authoritative exact-checkpoint labels and modality, resolve the YOLO d/D contradiction where relevant, secure model/data rights, perform independent patient-disjoint licensed real-image evaluation with reviewed ground truth, obtain authorized clinical review, assess the final release on physical hardware, and complete applicable clinical/legal authorization. Until then clinical use remains PROHIBITED and AI-to-ICD support remains 0/108.
